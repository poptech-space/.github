### 🚀 Наши ключевые решения

#### 1. [Авито Быстрые Ответы — Расширение для Chrome](https://chromewebstore.google.com/detail/hngdekjlclppfbnogomclobgmbbgadpl)
Бесплатное расширение для продавцов и мастеров на Авито. Встраивает панель быстрых шаблонов и ходовых эмодзи прямо под строку ввода в веб-чате Авито.
* **1 клик**: мгновенная подстановка фразы без хождений по подменю и плюсикам.
* **Без лимитов**: сохраняйте неограниченное число шаблонов со сквозной синхронизацией через Google-аккаунт.
* **100% Client-Side**: работает локально в браузере, не требует API Авито и платных тарифов.
* 📦 **[Установить из Chrome Web Store](https://chromewebstore.google.com/detail/hngdekjlclppfbnogomclobgmbbgadpl)** | 🌐 **[Лендинг продукта](https://neuro.poptech.space/avito)**

#### 2. [avito-telegram-bridge](https://github.com/poptech-space/avito-telegram-bridge)
Автономный двусторонний серверлесс-мост между **Авито (Messenger API)** и **Telegram (Bot API)**.
* Мгновенный автоответ покупателям за 1.5 секунды для удержания бейджа «Отвечает за минуту».
* Пуш карточки лида мастеру в личный Telegram.
* Двусторонняя переписка: мастер отвечает прямо из Telegram через Reply (свайп) — ответ мгновенно уходит в чат Авито.
* **0 ₽/мес на инфраструктуру**: работает на нативном [Telegram Serverless](https://github.com/poptech-space/avito-telegram-bridge/tree/main/examples/telegram-serverless) (без сторонних облаков) либо на Yandex Cloud Functions в рамках Free Tier (1 млн вызовов в месяц бесплатно).

#### 3. Шаблоны ботов для мессенджера МАКС (MAX)
Решения для официального Bot API мессенджера МАКС (`platform-api2.max.ru`):
* Квиз-боты для расчета смет и сбора заявок для верифицированного бизнеса (Самозанятые, ИП, Юрлица).
* Поддержка корневых SSL-сертификатов Минцифры РФ в облачном рантайме.
